📜 Logger

A small console logger with a colour and an emoji per level, scoped labels, and a listener API. The dispatcher, the event bus and shared states already report through it.

🎚️Levels

Click a level and look at the panel, then open the browser console (DevTools) to see the coloured version.

import { Logger } from 'html-scoped-component-importer';

const logger = new Logger({ scope: 'playground' });
logger.debug('Fine-grained detail');
logger.info('Something happened', { details: 'go here' });
logger.warn('Careful');
logger.error('Something broke', new Error('oops'));
logger.celebrate('Shipped it! 🎉');                // console.log with a gradient badge

🏷️Scopes

withScope() returns a logger with another label that shares the same listeners. This demo gives each part its own scope: ⚡ dispatcher, 📦 dispatcher, 📬 events, 🛒 cart.

const checkoutLogger = logger.withScope('🛒 checkout');
checkoutLogger.info('Payment form ready');

new ComponentDispatcher({ logger: logger.withScope('⚡ dispatcher') });

👂Listening to entries

onEntry() receives every entry as data. The Live log panel on the right is built with it.

const stop = logger.onEntry(({ level, scope, message, details, timestamp }) => {
  logPanel.append(`${scope} ${message}`);
});

🤫Development only

By default the logger is enabled only when your bundler replaces process.env.NODE_ENV with "development"; in production builds it prints nothing. Override it either way:

new Logger({ enabled: true });  // always on (this demo)
new Logger({ enabled: false }); // always silent
