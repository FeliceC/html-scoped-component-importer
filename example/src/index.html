🧩 html-scoped-component-importer

Bind TypeScript classes to HTML with a data-component attribute. Everything below is live: click around and watch the queue and the log react.

npm install html-scoped-component-importer GitHub npm

📬Events with a queue + shared state

Products update a SharedState (the cart badge subscribes to it) and emit notify. While no listener is connected, events wait in the queue; connect the listener and they are delivered in order.

👉 Add a few products, then press Connect listener. Disconnect it and try again.

    ⚡Async mode

    The dispatcher resolves COMPONENTS/Greeting with a dynamic import(): webpack ships it as its own chunk, fetched only when the element exists.

    <div data-component="Greeting"></div>

const dispatcher = new ComponentDispatcher();
await dispatcher.importAsyncComponents();

    🕒Sync mode with a custom selector

    A second dispatcher uses an explicit registry and its own attribute. No dynamic import, so it works with any bundler.

    <span data-sync-component="Clock"></span>

const dispatcher = new ComponentDispatcher();
dispatcher.Selector = '[data-sync-component]';
await dispatcher.importComponents({ Clock });

    🎛️Several components, options from data attributes

    Counter reads its start value and step from data-option-*; Highlight decorates the same element.

    <div data-component="Counter, Highlight"
     data-option-start="10" data-option-step="5"></div>

    👀Observing DOM changes

    With observeDomChanges() new elements are mounted automatically and removed ones get _destroy(). Watch the log.

    const stopObserving = dispatcher.observeDomChanges();

    💥Error overlay

    A component that throws does not break the others. In development builds it is replaced by an overlay with the stack trace.
